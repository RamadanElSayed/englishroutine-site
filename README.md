# English Routine — landing page

Static site: `index.html` (Arabic, RTL), `en.html`, `privacy.html`, `img/`.

Hosting (free): a **public** GitHub repo `englishroutine-site` with this folder as its root. The workflow in
`.github/workflows/pages.yml` publishes it to GitHub Pages on every push (`https://ramadanelsayed.github.io/englishroutine-site/`).
A custom domain can be added later in the repo's Pages settings.

Edit here (the app repo, `site/`), then copy to the site repo and push.
